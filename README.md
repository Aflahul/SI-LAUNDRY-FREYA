# 🧺 Sistem Informasi Jasa Laundry – Freya Laundry Bajo

Proyek ini adalah **aplikasi web berbasis Laravel** yang dirancang untuk membantu pengelolaan usaha laundry di **Freya Laundry Bajo**.  
Aplikasi ini mendukung proses pencatatan transaksi, manajemen pelanggan, layanan, hingga laporan, sehingga operasional laundry lebih cepat, efisien, dan terkomputerisasi.

---

## 🚀 Fitur Utama

- **Manajemen Pelanggan**  
  Tambah, edit, dan kelola data pelanggan dengan mudah.

- **Input & Kelola Transaksi**  
  Pencatatan transaksi laundry berdasarkan layanan (kiloan, satuan, express, dll).

- **Status Order**  
  Update status cucian (proses, selesai, diambil).

- **Manajemen Layanan & Harga**  
  Admin dapat menambahkan atau mengubah jenis layanan beserta tarifnya.

- **Laporan**  
  Rekap transaksi harian, mingguan, bulanan untuk mendukung analisis usaha.

---

## 🛠️ Teknologi yang Digunakan

- [Laravel 10](https://laravel.com/) – Backend & framework utama  
- [MySQL/MariaDB](https://www.mysql.com/) – Database  
- [Blade/Tailwind CSS](https://tailwindcss.com/) – Frontend & UI sederhana  
- [PHP 8+](https://www.php.net/) – Bahasa pemrograman
